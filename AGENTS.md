## Project status tracking

- Read `docs/05-Project-Status.md` before starting major feature work to understand recorded progress.
- Whenever a major feature is built or meaningfully advanced, update that file as part of the same work. Add an entry for a new feature or update its existing entry as it progresses.
- Record the feature's status, last updated date, a concise summary of what is implemented, and any remaining work or known limitations. Use `In progress`, `Blocked`, or `Completed` accurately; do not mark planned or partial work as completed.
- Preserve previous milestones so the file remains a useful project history. Routine fixes and minor cosmetic changes do not need separate entries unless they materially change a feature's status.
